Phase 1 - 
In this phase, I created a Song class with a title, artist, and duration to store information about each song. I also created a SinglyLinkedList class with a private inner Node class. Each node holds a song and a reference to the next node in the list. I implemented the addLast() method to add songs to the end of the list and the display() method to print each song using the toString() method. I tested my program by adding three songs and verified that they displayed in the correct order. A linked list stores its elements differently from an array. An array stores elements in indexed positions, while a linked list uses nodes that connect to one another through references. Each node points to the next node, allowing the list to keep track of its elements. In my program, I used this connection to link the three songs together and display them in order.

Phase 2 -
When remove() is called, it unlinks a node by changing the references so the list skips over the song being removed. If the song is the first node, the head reference is updated to point to the next node. If the song is somewhere else in the list, the previous node's next reference is changed to point to the node after the one being removed. The iterator keeps track of its position by storing references to the current node, the last node returned, and the previous node. This helps it keep its place in the list while removing a song. After a node is removed, the iterator updates its references so it can continue moving through the list without losing track of the remaining songs. 

Phasae 3 - 
Inserting a song into the middle of a linked list is O(n) because you have to go through the list to find the right spot. Once you find it, connecting the new node takes O(1) time. Inserting a song into the middle of an array-based list is also O(n) because you may need to shift other elements to make room. Both take O(n) time overall, but an array-based list may require more operations because you have to shift multiple elements. A linked list only needs to change two links once it reaches the right spot.

Phase 4- 
The benefit of using a separate SortedLinkedList class instead of having a single list with an addSorted() method is that the list automatically keeps songs in the correct order whenever I use add(). With a single list, I would have to remember to call addSorted() when I want to insert a song in sorted order. Using a Comparator in the constructor also lets me choose different sorting rules, such as title, artist, or duration, without rewriting the class. This makes my code easier to reuse and more flexible.
